# Lab 1 — Version Control

## Description

This project contains Java methods and unit tests implemented with JUnit 5.

## Requirements

* JDK 17
* Apache Maven
* IntelliJ IDEA

## Run Tests

1. Open the project in IntelliJ IDEA.
2. Set JDK 17 as the Project SDK.
3. Reload the Maven project.
4. Open the Maven tool window.
5. Run the `test` lifecycle goal.

## Technologies

* Java 17
* Maven
* JUnit 5
